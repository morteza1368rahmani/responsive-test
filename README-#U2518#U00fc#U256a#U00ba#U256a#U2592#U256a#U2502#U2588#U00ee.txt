راهنمای ساخت فایل APK از این پروژه
======================================

این یک پروژه کامل اندروید استودیو (Android Studio) است که فایل HTML شما
(bus-boostanzar.html) را داخل یک WebView نمایش می‌دهد.

⚠️ نکته مهم: فایل HTML شما به تصویر پس‌زمینه‌ای به نام "bg.png" اشاره می‌کند
که برایم ارسال نشده بود. قبل از build گرفتن، فایل bg.png خودتان را داخل
این مسیر کپی کنید:

    app/src/main/assets/www/bg.png

اگر این فایل را نگذارید، برنامه اجرا می‌شود ولی پس‌زمینه خالی می‌ماند.

مراحل ساخت APK:
----------------
۱. نرم‌افزار Android Studio را از سایت رسمی دانلود و نصب کنید:
   https://developer.android.com/studio

۲. این پوشه (bus-boostanzar-app) را باز کنید:
   File > Open... و پوشه پروژه را انتخاب کنید.

۳. صبر کنید تا Gradle Sync تمام شود (نیاز به اینترنت دارد تا وابستگی‌ها
   دانلود شوند).

۴. از منوی بالا مسیر زیر را بروید:
   Build > Build Bundle(s) / APK(s) > Build APK(s)

۵. بعد از اتمام build، روی نوتیفیکیشن پایین صفحه کلیک کنید
   یا فایل APK را از این مسیر بردارید:
   app/build/outputs/apk/debug/app-debug.apk

۶. این فایل APK را می‌توانید مستقیماً روی گوشی اندرویدی نصب کنید
   (لازم است نصب از منابع ناشناس/Unknown sources را در تنظیمات گوشی فعال کنید).

تغییر نام برنامه یا آیکون:
---------------------------
- نام برنامه: app/src/main/res/values/strings.xml
- آیکون برنامه: فایل‌های app/src/main/res/mipmap-*/ic_launcher.png
  (آیکون فعلی فقط یک نمونه ساده سبز رنگ است و می‌توانید جایگزینش کنید)

اگر بخواهید نسخه امضاشده (Release, برای انتشار در بازار / Google Play)
بسازید، به راهنمای امضای اپلیکیشن اندروید نیاز دارید که در مستندات رسمی
Android Studio توضیح داده شده:
https://developer.android.com/studio/publish/app-signing


روش جایگزین: ساخت APK با GitHub Actions (بدون نیاز به Android Studio)
=======================================================================
این پروژه یک فایل تنظیمات آماده در مسیر .github/workflows/build.yml دارد
که به‌صورت خودکار روی سرورهای GitHub، APK را می‌سازد. این روش مناسب کسانی
است که با فیلترینگ یا مشکل دانلود در Android Studio مواجه‌اند.

مراحل:
------
۱. یک حساب رایگان در github.com بسازید (اگر ندارید).

۲. یک مخزن (Repository) جدید بسازید:
   - روی دکمه سبز "New" یا "+" بالای صفحه کلیک کنید
   - یک اسم بگذارید، مثلاً bus-boostanzar-app
   - آن را Public یا Private بگذارید (فرقی نمی‌کند)
   - Create repository را بزنید

۳. تمام فایل‌های این پوشه (bus-boostanzar-app) را در آن مخزن آپلود کنید:
   - در صفحه مخزن، روی "uploading an existing file" کلیک کنید
   - تمام فایل‌ها و پوشه‌ها (از جمله پوشه مخفی .github) را بکشید و رها کنید
   - پایین صفحه "Commit changes" را بزنید
   (نکته: آپلود از طریق مرورگر گاهی پوشه‌های تو در تو یا فایل‌های مخفی را
   درست منتقل نمی‌کند؛ اگر مشکلی دیدید، از نرم‌افزار GitHub Desktop
   استفاده کنید که ساده‌تر و مطمئن‌تر است: desktop.github.com)

۴. به تب "Actions" در بالای صفحه مخزن بروید.
   - اگر پیامی درباره فعال‌سازی Actions دید، آن را تایید کنید
   - باید یک workflow با نام "Build APK" ببینید که به‌صورت خودکار اجرا
     شده یا در حال اجراست (دایره زرد در حال چرخش = در حال اجرا،
     تیک سبز = تمام شد)

۵. صبر کنید (معمولاً ۲ تا ۵ دقیقه طول می‌کشد) تا تیک سبز بیاید.

۶. روی همان اجرای موفق (Run) کلیک کنید، پایین صفحه بخش "Artifacts" را
   پیدا کنید و روی "bus-boostanzar-apk" کلیک کنید تا دانلود شود.
   (فایل دانلودی یک zip است که فایل app-debug.apk داخلش هست)

۷. فایل app-debug.apk را به گوشی منتقل و نصب کنید.
